## 📱 COMO USAR

1. **Abra o arquivo:**
   ```
   catalogo-completo.html
   ```

2. **Use a busca** para encontrar serviços específicos

3. **Filtre** por secretaria ou prioridade

4. **Clique em um serviço** para ver todos os detalhes

5. **Use "Solicitar Serviço"** para criar um chamado (futuro)
