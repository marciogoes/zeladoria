# 🚀 INÍCIO - Sistema de Zeladoria Urbana

## ⚡ COMECE EM 3 PASSOS (5 minutos)

### 1️⃣ Instalar
```bash
# Linux/Mac
./install.sh

# Windows (PowerShell como Admin)
.\install.ps1
```

### 2️⃣ Iniciar
```bash
# Linux/Mac
./start.sh

# Windows
.\start.ps1
```

### 3️⃣ Acessar
```
http://localhost:8001/static/index.html
```
