## 🐛 PROBLEMAS?

### **Backend não inicia?**
```bash
# Verifique se Python está instalado
python --version

# Execute a instalação novamente
./install.sh  # ou .\install.ps1
```

### **Sem dados no sistema?**
```bash
python seed.py
```

### **Testes falhando?**
```bash
# Certifique-se que o backend está rodando
./start.sh

# Execute os testes
python test_suite.py
```

**Mais ajuda:** Veja [GUIA_RAPIDO_DASHBOARD.md](GUIA_RAPIDO_DASHBOARD.md) → Seção "Troubleshooting"
