 💡 DICAS ÚTEIS
═══════════════════════════════════════════════════════════════════════════

DESENVOLVIMENTO
────────────────────────────────────────────────────────────────────────────
  • Use React DevTools para debug
  • Console do navegador (F12) para ver erros
  • Network tab para ver requisições HTTP
  • FastAPI /docs para testar APIs
  • Mantenha 2 terminais abertos (backend + frontend)

PERFORMANCE
────────────────────────────────────────────────────────────────────────────
  • Use paginação para listas grandes
  • Implemente debounce na busca
  • Use memo/useMemo para otimizar React
  • Adicione índices no banco de dados
  • Use cache quando apropriado

PROBLEMAS COMUNS
────────────────────────────────────────────────────────────────────────────
  • Serviços não aparecem? → POPULAR_CATALOGO.bat
  • Erro CORS? → Verifique main.py
  • Porta ocupada? → Mude a porta ou feche app
  • npm não reconhecido? → Instale Node.js
  • python não reconhecido? → Instale Python
