🚀 COMO INICIAR
═══════════════════════════════════════════════════════════════════

OPÇÃO 1 - Setup Automático (RECOMENDADO)
─────────────────────────────────────────────────────────────────
1. Execute: SETUP_COMPLETO.bat
2. Execute: INICIAR_BACKEND.bat (terminal 1)
3. Execute: INICIAR_FRONTEND.bat (terminal 2)
4. Acesse: http://localhost:5173


OPÇÃO 2 - Manual
─────────────────────────────────────────────────────────────────
1. cd frontend
2. npm install
3. npm install lucide-react
4. npm run dev


🎨 FUNCIONALIDADES IMPLEMENTADAS
═══════════════════════════════════════════════════════════════════

TAB 1: CATÁLOGO DE SERVIÇOS
─────────────────────────────────────────────────────────────────
✅ Lista de serviços com paginação
✅ Busca por nome ou código
✅ Filtros:
   • Categoria
   • Prioridade (Emergencial, Alta, Média, Baixa, Agendável)
   • Status (Ativo, Suspenso, Inativo)
   • Apenas gratuitos (checkbox)
   • Atendimento online (checkbox)
✅ Cards interativos com:
   • Código do serviço
   • Nome e descrição
   • SLA em horas
   • Custo (gratuito ou valor)
   • Categoria
   • Avaliação (estrelas)
✅ Modal de detalhes completos:
   • Todas as informações do serviço
   • Documentos necessários
   • Requisitos
   • Canais de atendimento
   • Estatísticas (se disponíveis)


TAB 2: CHAMADOS COM SLA
─────────────────────────────────────────────────────────────────
✅ Lista de chamados
✅ Indicadores visuais de SLA:
   🟢 Verde: No prazo (> 24h restantes)
   🟠 Laranja: Crítico (< 24h restantes)
   🔴 Vermelho: Vencido
✅ Informações exibidas:
   • Protocolo
   • Status do chamado
   • Título e descrição
   • Status do SLA
   • Horas restantes ou vencidas
✅ Botão "Reclassificar"
✅ Modal de reclassificação:
   • Busca de serviços
   • Seleção visual
   • Confirmação com detalhes


TAB 3: DASHBOARD
─────────────────────────────────────────────────────────────────
✅ KPIs principais:
   📋 Total de Serviços
   ✅ Serviços Ativos
   📁 Total de Categorias
   ⏱️ Taxa de Cumprimento SLA
✅ Gráfico de distribuição por prioridade
✅ Top 5 categorias mais solicitadas
✅ Estatísticas em tempo real
